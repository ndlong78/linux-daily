Nhiều default gateway: policy routing không cắt SSH

Host nhiều uplink có thể gửi reply ra sai gateway dù route mặc định nhìn có vẻ hợp lệ. Linux dùng policy routing với rule/table; FreeBSD dùng nhiều FIB — cùng mục tiêu nhưng khác lệnh.

TRỤC · NETWORKINGĐỘ KHÓ · NÂNG CAO

01 Bối cảnh thực tế

Máy có hai uplink có thể nhận request qua A nhưng reply ra B, làm SSH/VPN hoặc NAT hoạt động chập chờn. Thay route từ xa còn có thể cắt chính đường quản trị.

02 Kiến thức cốt lõi

  • Linux xét policy rule trước khi tra routing table; đọc ip rule cùng ip route show table all.
  • FreeBSD dùng nhiều FIB và setfib; không có ip rule.
  • Trước thay đổi phải chụp đường tới IP quản trị và có rollback/OOB console.

03 Bảng lệnh song song theo distro

Ubuntu / Xubuntu
ip rule show
ip route show table main
ip route show table all | sed -n '1,80p'
Debian
ip rule show
ip route show table main
ip route show table all | sed -n '1,80p'
Fedora
ip rule show
ip route show table main
ip route show table all | sed -n '1,80p'
FreeBSD — KHÁC Linux
sysctl net.fibs
setfib 0 netstat -rn
route -n get default

04 Ví dụ thực hành từng bước

Bài thực hành chỉ đọc: thay <ADMIN_IP> bằng IP quản trị và xác định interface, gateway cùng table/FIB đang phục vụ đường đó.

Linux

Linux
ip route get '<ADMIN_IP>'
ip rule show
ip route show table main

FreeBSD

FreeBSD
route -n get '<ADMIN_IP>'
sysctl net.fibs
setfib 0 netstat -rn

Expected Output

Xác định được next-hop, interface và table/FIB cho <ADMIN_IP> trước khi đề xuất thay đổi.

05 Cạm bẫy / lỗi thường gặp và cách xử lý

  • Thêm default route thứ hai mà không thiết kế source-based policy, tạo asymmetric routing.
  • Xóa route cũ trước khi có rollback.
  • Áp ip rule lên FreeBSD thay vì FIB/setfib.

06 Lưu ý bảo mật

Không thử route change production qua phiên SSH duy nhất. Dùng console/OOB hoặc rollback tự động và bảo vệ đường quản trị trước.

07 Bài tập nhỏ để tự luyện

Vẽ policy cho hai source subnet đi ra hai uplink; ghi lệnh dự kiến và rollback cho Linux/FreeBSD nhưng không chạy trên production.
