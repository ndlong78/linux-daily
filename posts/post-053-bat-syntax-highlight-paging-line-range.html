bat: xem file có syntax highlight, paging và line range

Đọc file nhanh hơn với syntax highlight, paging và line range mà vẫn biết khi nào phải quay về output plain cho script.

TRỤC · CÔNG CỤ MỚIĐỘ KHÓ · CƠ BẢN~10 PHÚT

Tested on: Ubuntu/Xubuntu 24.04 LTS · Debian 13 stable · Fedora 42 · FreeBSD 14.4-RELEASE

Last verified: 2026-08-22 · đối chiếu upstream bat và package catalog chính thức của Ubuntu, Debian, Fedora; FreeBSD install path được upstream bat ghi rõ.

Mục tiêu

Dùng bat để đọc file có syntax highlight, kiểm soát pager và chỉ tải vùng dòng cần xem, đồng thời giữ output ổn định khi chuyển sang pipeline/script.

Yêu cầu tiên quyết

  • Có terminal trên Ubuntu hoặc Xubuntu, Debian, Fedora hoặc FreeBSD.
  • Có quyền sudo/root chỉ cho bước cài và gỡ package; các thao tác đọc file chạy bằng user thường.
  • Lab dùng file tạm trong /tmp; không sửa file cấu hình production.
  • Đã quen với cat/less cơ bản; bài này tập trung vào workflow đọc file tương tác.

01 Bối cảnh thực tế

cat tốt khi cần output tối giản cho pipeline, nhưng khi đọc một file cấu hình hoặc source dài bằng mắt, line number, syntax highlight và paging giúp định vị nhanh hơn. bat bổ sung các lớp hiển thị này mà vẫn đọc file hoặc standard input.

Điểm quan trọng là không biến bat thành mặc định mù quáng cho mọi script. Upstream cho biết khi stdout không phải terminal tương tác, bat tự giảm decorations và hành xử gần với cat; tuy vậy script cần output ổn định vẫn nên dùng cat, sed hoặc gọi rõ --plain --color=never --paging=never.

02 Kiến thức cốt lõi

  • Syntax highlighting: bat nhận diện nhiều ngôn ngữ theo filename/extension; với stdin có thể chỉ định --language.
  • Paging: mặc định là tự động. --paging=never phù hợp khi muốn output liên tục; --paging=always ép mở pager trong terminal.
  • Line range: --line-range 10:20 chỉ hiển thị một vùng dòng; dạng :200 hữu ích khi preview file lớn.
  • Output style: --style=numbers,changes chọn decorations; --plain bỏ toàn bộ decorations.
  • Tên executable: package tên bat nhưng trên Debian 13 executable chính thức vẫn có thể là batcat; bài dùng biến BAT để không đoán.

03 Các bước thực hiện

  1. Cài package đúng theo hệ điều hành.

    Ubuntu / Xubuntu

    Run as: sudo

    sudo apt update
sudo apt install -y bat

    Debian

    Run as: sudo

    sudo apt update
sudo apt install -y bat

    Fedora

    Run as: sudo

    sudo dnf install -y bat

    FreeBSD — KHÁC Linux

    FreeBSD dùng pkg; không dùng APT/DNF hoặc systemd.

    Run as: root

    pkg install -y bat

  2. Xác định executable thay vì giả định tên lệnh.

    Mọi hệ

    Run as: user

    if command -v bat >/dev/null 2>&1; then
  BAT=bat
elif command -v batcat >/dev/null 2>&1; then
  BAT=batcat
else
  printf '%s\n' 'Không tìm thấy bat/batcat trong PATH' >&2
  exit 1
fi
printf 'BAT=%s\n' "$BAT"
"$BAT" --version

    Ubuntu/Xubuntu và Debian có thể khác nhau theo package build. Từ bước này, mọi lệnh gọi qua "$BAT".

  3. Tạo file lab và xem syntax highlight với line number.

    Mọi hệ

    Run as: user

    workdir="$(mktemp -d /tmp/linux-daily-bat.XXXXXX)"
awk 'BEGIN { for (i=1; i<=30; i++) printf "key_%02d=value_%02d\n", i, i }' > "$workdir/sample.conf"
"$BAT" --language=ini --style=numbers --paging=never "$workdir/sample.conf"

    --language=ini làm kết quả deterministic hơn cho file mẫu thay vì phụ thuộc auto-detection.

  4. Chỉ đọc vùng dòng cần thiết.

    Mọi hệ

    Run as: user

    "$BAT" --language=ini --style=numbers --paging=never --line-range 10:16 "$workdir/sample.conf"

    Với preview file rất dài, có thể dùng dạng --line-range :200 để giới hạn phần đầu file được hiển thị.

  5. Phân biệt terminal tương tác với output cho pipeline.

    Mọi hệ

    Run as: user

    "$BAT" --paging=never --plain --color=never "$workdir/sample.conf" | sed -n '10,12p'

    Khi mục tiêu là xử lý text, tắt pager/color/decorations rõ ràng giúp tránh phụ thuộc vào trạng thái TTY. Với script đơn giản, dùng trực tiếp sed hoặc cat vẫn là lựa chọn ít bất ngờ hơn.

04 Kiểm chứng

Kiểm ba thuộc tính độc lập: binary có thật, line range đúng phạm vi và chế độ plain không thêm decorations.

Mọi hệ

Run as: user

"$BAT" --version
"$BAT" --language=ini --paging=never --plain --color=never --line-range 10:12 "$workdir/sample.conf"

Expected Output / Kết quả mong đợi

bat 0.x.y
key_10=value_10
key_11=value_11
key_12=value_12

Version cụ thể phụ thuộc repository của từng hệ; không hard-code một version làm điều kiện pass.

Gỡ / Hoàn tác

Xóa thư mục lab trước, sau đó gỡ package nếu chỉ cài cho bài này.

Mọi hệ — xóa dữ liệu lab

Run as: user

test -n "${workdir:-}" && case "$workdir" in /tmp/linux-daily-bat.*) rm -rf -- "$workdir" ;; *) printf '%s\n' 'Từ chối xóa: workdir không đúng pattern lab' >&2; exit 1 ;; esac

Ubuntu / Xubuntu

Run as: sudo

sudo apt remove -y bat

Debian

Run as: sudo

sudo apt remove -y bat

Fedora

Run as: sudo

sudo dnf remove -y bat

FreeBSD

Run as: root

pkg delete -y bat

05 Lưu ý & Khắc phục lỗi

  • bat: command not found sau khi cài: chạy command -v batcat. Debian package catalog hiện vẫn ghi executable /usr/bin/batcat ở một số build.
  • Không thấy màu khi pipe: đó là hành vi có chủ ý khi stdout không phải terminal. Chỉ dùng --color=always khi chương trình nhận phía sau thực sự hiểu ANSI color.
  • Pager gây khó trong automation: thêm --paging=never; với script, cân nhắc quay về cat/sed.
  • Syntax nhận sai: dùng --language=<name> và kiểm tên hợp lệ bằng "$BAT" --list-languages.
  • File rất lớn: dùng --line-range để giới hạn vùng đọc thay vì render toàn bộ file chỉ để xem vài dòng.

06 Bảo mật & vận hành

bat là trình xem, không phải sanitizer. Không xem nội dung nhạy cảm trên terminal đang được ghi hình hoặc chia sẻ màn hình. Khi dữ liệu đến từ nguồn không tin cậy, terminal control sequences có thể gây nhầm lẫn; các version mới của upstream có option sanitize/strip ANSI, nhưng availability phụ thuộc version nên cần kiểm "$BAT" --help trước khi dùng.

Không alias cat thành bat trên server production nếu script hoặc runbook đang dựa vào hành vi byte-oriented đơn giản của cat. Dùng bat như công cụ đọc tương tác; giữ tool xử lý text cho automation.

07 Bài tập tự luyện

  1. Dùng --list-languages để tìm tên syntax cho JSON hoặc YAML rồi ép language cho một file không có extension.
  2. So sánh --style=full, --style=numbers và --plain trên cùng một file.
  3. Đọc dòng 100–120 của một file dài bằng --line-range, sau đó đối chiếu với sed -n '100,120p'.
  4. Giải thích vì sao --paging=never phù hợp cho pipeline hơn --paging=always.
