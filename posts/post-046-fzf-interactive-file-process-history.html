Công cụ mới · fzf

fzf cho chọn file, process và history tương tác

Dùng fzf để chọn file, process và history như một lớp tương tác; luôn kiểm tra selection trước khi chuyển thành action.

TRỤC · CÔNG CỤ MỚIĐỘ KHÓ · CƠ BẢN~10 PHÚT

Tested on: Ubuntu/Xubuntu 24.04 LTS · Debian 13 stable · Fedora 42 · FreeBSD 14.4-RELEASE

Last verified: 2026-08-15 · đối chiếu upstream fzf, Debian manpage và Fedora package catalog; walkthrough chỉ cài package và chọn dữ liệu, không tự thực thi selection.

Mục tiêu

Dùng fzf để thu hẹp danh sách file, process và command history, rồi tách bước chọn khỏi bước hành động để giảm thao tác nhầm.

Yêu cầu tiên quyết

  • Đã nắm bài #039 về fd hoặc biết cách tạo một danh sách dòng bằng find, ps hay shell history.
  • Có terminal tương tác; fzf cần TTY để chọn trực tiếp.
  • Có quyền sudo/root chỉ cho bước cài hoặc gỡ package.
  • Lab không chứa file/process production cần tác động; bài không thực hiện xóa file hay gửi signal cho process.

01 Bối cảnh thực tế

Khi danh sách dài, gõ chính xác tên file, PID hoặc một command cũ dễ chậm và dễ nhầm. fzf nhận danh sách từ standard input, cho phép fuzzy-match tương tác và ghi item được chọn ra standard output. Vì output có thể đến từ dữ liệu thay đổi theo thời gian, cách vận hành an toàn là chọn trước, quan sát lại selection, rồi mới quyết định hành động tiếp theo.

02 Kiến thức cốt lõi

  • fzf là interactive filter cho danh sách, không chỉ là file finder.
  • Nguồn dữ liệu có thể là find, ps, history, fc hoặc bất kỳ command nào xuất một item mỗi dòng.
  • Selection được ghi ra standard output. Capture selection vào biến hoặc in lại trước khi dùng cho bước tiếp theo.
  • --filter chạy chế độ lọc không tương tác; hữu ích cho verification và test deterministic.
  • Shell integration như CTRL-R/CTRL-T phụ thuộc version/package. Upstream lưu ý các option integration mới chỉ có ở fzf gần đây, nên bài này dùng pipeline cơ bản chạy ổn định hơn giữa distro.

Cài package theo distro

Ubuntu/Xubuntu và Debian — chạy bằng user có quyền sudo.

Run as: sudo

sudo apt update
sudo apt install -y fzf

Fedora — chạy bằng user có quyền sudo.

Run as: sudo

sudo dnf install -y fzf

FreeBSD

FreeBSD dùng pkg, không dùng APT/DNF hoặc systemd. Chạy bằng root.

Run as: root

pkg install -y fzf

03 Các bước thực hiện

  1. Xác nhận version và hành vi filter cơ bản.

    Tất cả hệ — chạy bằng user thường.

    Run as: user

    fzf --version
printf 'alpha\nbeta\ngamma\n' | fzf --filter='bet'

    Lệnh thứ hai không mở UI; nó kiểm tra deterministic rằng input được lọc và ghi ra stdout.

  2. Chọn một file rồi chỉ in selection.

    Ubuntu/Xubuntu, Debian, Fedora và FreeBSD — chạy bằng user thường trong thư mục lab có tên file thông thường, không chứa newline.

    Run as: user

    selected_file="$(find . -maxdepth 2 -type f -print | fzf --prompt='file> ')"
printf 'selected: %s\n' "$selected_file"

    Không nối output này trực tiếp vào lệnh xóa hoặc ghi đè. Nếu cần xử lý filename tùy ý có newline, phải thiết kế pipeline NUL-delimited riêng; lab này không giả định line-based input là an toàn cho mọi filename.

  3. Chọn một process để quan sát, không gửi signal.

    Linux — chạy bằng user thường.

    Run as: user

    selected_process="$(ps -eo pid=,user=,comm=,args= | fzf --prompt='process> ')"
printf '%s\n' "$selected_process"

    FreeBSD

    FreeBSD dùng cú pháp ps riêng. Chạy bằng user thường.

    Run as: user

    selected_process="$(ps ax -o pid=,user=,comm=,args= | fzf --prompt='process> ')"
printf '%s\n' "$selected_process"

    Selection có thể stale ngay sau khi chọn vì PID/process thay đổi. Nếu sau này cần thao tác với PID, phải parse và xác minh lại process identity ở một bước riêng.

  4. Tìm command cũ trong Bash history.

    Ubuntu/Xubuntu, Debian hoặc Fedora khi shell hiện tại là Bash — chạy bằng user thường.

    Run as: user

    selected_history="$(history | fzf --scheme=history --tac --prompt='history> ')"
printf '%s\n' "$selected_history"

    Bài chỉ in dòng được chọn. Không dùng eval để chạy lại history chưa review.

  5. Tìm history trên FreeBSD theo shell đang dùng.

    FreeBSD

    Với sh, dùng builtin fc. Chạy bằng user thường.

    Run as: user

    selected_history="$(fc -l 1 | fzf --scheme=history --tac --prompt='history> ')"
printf '%s\n' "$selected_history"

    Nếu login shell là csh/tcsh, dùng builtin history của shell đó làm nguồn input. Không áp cấu hình Bash vào FreeBSD theo mặc định.

  6. Kiểm tra selection trước khi dùng ở bước tiếp theo.

    Tất cả hệ — chạy bằng user thường. Ví dụ với file đã chọn:

    Run as: user

    test -n "$selected_file" && printf 'candidate: %s\n' "$selected_file"
test -f "$selected_file" && file "$selected_file"

    Nếu selection rỗng hoặc target không còn tồn tại, dừng. Fuzzy match không phải authorization để thay đổi target.

04 Kiểm chứng

Kiểm tra package, deterministic filter và một selection tương tác mà không có side effect.

Run as: user

command -v fzf
printf 'alpha\nbeta\ngamma\n' | fzf --filter='bet'

Expected Output / Kết quả mong đợi

/usr/bin/fzf
beta

Đường dẫn binary có thể khác tùy package. Điều cần xác nhận là command -v trả về một executable và filter trả đúng dòng beta. Trong bài tập tương tác, selection được in lại nhưng không tự thực thi.

Gỡ / Hoàn tác

Bài không sửa shell startup file. Nếu không cần fzf nữa, gỡ package theo đúng hệ.

Ubuntu/Xubuntu và Debian — chạy bằng user có quyền sudo.

Run as: sudo

sudo apt remove -y fzf

Fedora — chạy bằng user có quyền sudo.

Run as: sudo

sudo dnf remove -y fzf

FreeBSD

Chạy bằng root.

Run as: root

pkg delete -y fzf

05 Lưu ý & Khắc phục lỗi

  • UI không mở: xác nhận command chạy trong terminal tương tác; pipeline qua môi trường không có TTY không phù hợp với selection trực tiếp.
  • --scheme=history không có: package có thể cũ hơn upstream. Bỏ option này và vẫn dùng history | fzf --tac; không cài binary lạ chỉ để có feature mới.
  • History thiếu command mới: shell history có semantics riêng và có thể chưa flush từ session khác. Không coi danh sách là audit log đầy đủ.
  • Process đã biến mất: đây là race bình thường. Refresh danh sách và xác minh lại PID/command trước mọi hành động.
  • Filename có newline: line-based pipeline trong lab không đủ mạnh cho trường hợp này; dùng workflow NUL-delimited được thiết kế riêng thay vì cố escape sau khi chọn.

06 Bảo mật & vận hành

  • Không dùng pattern kiểu ... | fzf | sh, eval "$(...)" hoặc nối selection trực tiếp vào lệnh destructive.
  • Với process, PID là identifier ngắn hạn. Luôn xác minh lại owner, command và target trước thao tác có side effect.
  • Với file, giữ quoting quanh biến selection và kiểm tra type/path trước khi đọc, ghi hoặc chuyển file.
  • Không đặt preview command dành riêng cho file vào FZF_DEFAULT_OPTS toàn cục; upstream lưu ý fzf còn nhận process, history và nhiều loại input khác.
  • Shell integration là convenience layer. Trên fleet đa distro, pin version/policy trước khi rollout cấu hình key binding hàng loạt.

07 Bài tập tự luyện

Tạo một thư mục lab có 10 file, chọn một file bằng fzf và chỉ in path. Sau đó chọn một process và chỉ in dòng process. Cuối cùng tìm một command cũ trong history nhưng không chạy lại. Với mỗi phần, ghi rõ “input”, “selection”, “verification” và điểm nào mới được phép bắt đầu action.
