Networking · Packet capture

tcpdump có mục tiêu: DNS, TCP handshake và firewall evidence

Packet capture hữu ích nhất khi câu hỏi đủ hẹp. Bài này dùng tcpdump với interface, host/port filter và packet count để lấy bằng chứng mà không capture tràn lan.

TRỤC · NETWORKINGĐỘ KHÓ · TRUNG CẤP

01 Bối cảnh thực tế

Khi DNS timeout hoặc TCP không bắt tay được, log ứng dụng thường chưa đủ để biết packet có rời host hay reply có quay về. tcpdump cho bằng chứng ở network layer nhưng cần filter để không tạo dữ liệu thừa.

02 Kiến thức cốt lõi

  • -i chọn interface, -n/-nn tránh resolve tên, -c giới hạn số packet.
  • Capture filter như host, port, tcp, udp, icmp chạy trước khi packet được in.
  • FreeBSD có tcpdump trong base system; Linux thường cài package riêng.

03 Bảng lệnh song song theo distro

Ubuntu / Xubuntu
sudo apt update && sudo apt install tcpdump
ip route get 1.1.1.1
sudo tcpdump -D
Debian
sudo apt update && sudo apt install tcpdump
ip route get 1.1.1.1
sudo tcpdump -D
Fedora
sudo dnf install tcpdump
ip route get 1.1.1.1
sudo tcpdump -D
FreeBSD — KHÁC Linux
command -v tcpdump
route -n get default
sudo tcpdump -D

04 Ví dụ thực hành từng bước

Thay <IF> bằng interface lab. Capture chỉ metadata ICMP và giới hạn 6 packet; không dump payload.

Linux

Terminal 1
sudo tcpdump -ni '<IF>' -c 6 'icmp or icmp6'
Terminal 2
ping -c 2 1.1.1.1

FreeBSD

Terminal 1
sudo tcpdump -ni '<IF>' -c 6 'icmp or icmp6'
Terminal 2
ping -c 2 1.1.1.1

Expected Output

Capture cho thấy request/reply ICMP với IP nguồn/đích. Nếu chỉ thấy request, đó là evidence để tiếp tục kiểm route/firewall/upstream.

05 Cạm bẫy / lỗi thường gặp và cách xử lý

  • Capture mọi traffic không có -c rồi tạo dữ liệu quá lớn.
  • Bật name resolution khiến output chậm và vô tình sinh thêm DNS traffic.
  • Thấy packet rời interface rồi kết luận remote host đã nhận được.

06 Lưu ý bảo mật

Packet capture có thể chứa thông tin nhạy cảm. Giới hạn interface/filter/count, tránh payload nếu không cần và bảo vệ file pcap như log nhạy cảm.

07 Bài tập nhỏ để tự luyện

Viết ba filter riêng cho DNS port 53, TCP port 443 và traffic tới một IP cụ thể; mỗi filter phải có packet count giới hạn.
