Công cụ mới · ripgrep

ripgrep: tìm log và cấu hình nhanh mà không quét nhầm

`rg` giúp tìm pattern trong cây file rất nhanh, nhưng mặc định còn áp quy tắc ignore và bỏ qua một số file ẩn/binary. Biết rõ mặc định giúp bạn không kết luận “không có” quá sớm.

TRỤC · CÔNG CỤ MỚIĐỘ KHÓ · CƠ BẢN~12 PHÚT

Tested on: Ubuntu/Xubuntu 24.04 LTS · Debian 13 stable · Fedora 42 · FreeBSD 14.3-RELEASE

Last verified: 2026-08-09 · đối chiếu tài liệu official/upstream

Mục tiêu

Dùng ripgrep nhanh nhưng hiểu ignore, hidden và binary semantics để không kết luận sai.

Yêu cầu tiên quyết

Có cây file lab hoặc thư mục chỉ đọc; quyền cài package nếu rg chưa có.

01 Bối cảnh thực tế

`rg` giúp tìm pattern trong cây file rất nhanh, nhưng mặc định còn áp quy tắc ignore và bỏ qua một số file ẩn/binary. Biết rõ mặc định giúp bạn không kết luận “không có” quá sớm.

Mục tiêu là có bằng chứng trước và sau thao tác, đồng thời giữ khác biệt giữa Linux và FreeBSD rõ ràng để runbook có thể dùng trong vận hành thật.

02 Kiến thức cốt lõi

  • `rg PATTERN PATH` là điểm bắt đầu; thêm `-n`, `-i`, `-g` để giữ truy vấn hẹp và đọc được.
  • Mặc định ripgrep tôn trọng ignore files trong cây dự án; khi điều tra hệ thống, hãy biết khi nào cần `--hidden` hoặc `--no-ignore`.
  • Không dùng `rg -uuu /` như phản xạ đầu tiên: phạm vi quá rộng làm tăng I/O và lộ dữ liệu không cần thiết.

03 Các bước thực hiện

  1. Cài và kiểm phiên bản rg từ package manager.
  2. Tìm trong path/pattern hẹp trước.
  3. So sánh mặc định với --hidden/--no-ignore khi cần.
  4. Dùng glob/type/context để thu hẹp output.

Ubuntu và Xubuntu dùng cùng khối lệnh. Debian/Fedora được tách vì package hoặc service naming có thể khác. FreeBSD là nhánh riêng.

Ubuntu / Xubuntu

Run as: user

sudo apt update
sudo apt install ripgrep
rg --version
Debian

Run as: user

sudo apt update
sudo apt install ripgrep
rg --version
Fedora

Run as: user

sudo dnf install ripgrep
rg --version
FreeBSD — KHÁC Linux

Run as: root

sudo pkg install ripgrep
rg --version

04 Kiểm chứng

Kết quả mong đợi

  • rg tìm đúng pattern và exit status hợp lý.
  • Giải thích được file hidden/ignored bị bỏ qua mặc định.
  • Có thể mở rộng phạm vi mà không quét mù toàn filesystem.

Tạo cây lab trong `/tmp/linux-daily-rg`, gồm file cấu hình thường và file ẩn, sau đó so sánh truy vấn mặc định với `--hidden`.

Linux — Ubuntu/Xubuntu, Debian, Fedora

Linux

Run as: user

rm -rf /tmp/linux-daily-rg
mkdir -p /tmp/linux-daily-rg/app
printf 'listen=8080\ntimeout=30\n' > /tmp/linux-daily-rg/app/app.conf
printf 'token=demo-not-secret\n' > /tmp/linux-daily-rg/.env
rg -n 'listen|timeout' /tmp/linux-daily-rg
rg --hidden -n 'token' /tmp/linux-daily-rg

FreeBSD

FreeBSD

Run as: root

rm -rf /tmp/linux-daily-rg
mkdir -p /tmp/linux-daily-rg/app
printf 'listen=8080\ntimeout=30\n' > /tmp/linux-daily-rg/app/app.conf
printf 'token=demo-not-secret\n' > /tmp/linux-daily-rg/.env
rg -n 'listen|timeout' /tmp/linux-daily-rg
rg --hidden -n 'token' /tmp/linux-daily-rg

Expected Output

Lệnh đầu tìm thấy `listen` và `timeout`; truy vấn có `--hidden` mới bảo đảm quét file `.env` trong lab.

Cleanup / Revert

Linux / FreeBSD lab cleanup

Run as: user

rm -rf /tmp/linux-daily-rg

Gỡ / Hoàn tác

Hoàn tác thay đổi lab theo thứ tự ngược, khôi phục baseline đã ghi trước bài và kiểm chứng lại trước khi đóng phiên quản trị.

05 Lưu ý & Khắc phục lỗi

  • Quên rằng ignore/hidden rules có thể làm mất kết quả mong đợi.
  • Dùng regex quá rộng trên `/var/log` mà không giới hạn file type/glob.
  • Đưa secret thật vào command line hoặc output được lưu vào ticket/chat.

06 Lưu ý bảo mật

Khi tìm secret hoặc token, giới hạn path và không paste output nguyên văn. Dùng dữ liệu giả trong lab.

07 Bài tập nhỏ để tự luyện

Dùng `rg -g '*.conf'` tìm mọi dòng chứa `listen` trong lab, rồi thêm một file `.txt` có cùng từ và chứng minh glob loại nó ra.
