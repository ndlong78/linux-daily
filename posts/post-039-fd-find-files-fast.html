Công cụ mới · fd

fd: tìm file nhanh nhưng phải hiểu ignore và hidden

fd có syntax ngắn, smart case và filter theo type/extension, nhưng mặc định bỏ qua hidden files và .gitignore. Trên Ubuntu/Debian binary còn có tên fdfind.

TRỤC · CÔNG CỤ MỚIĐỘ KHÓ · CƠ BẢN

Tested on: Ubuntu/Xubuntu 24.04 LTS · Debian 13 stable · Fedora 42 · FreeBSD 14.3-RELEASE

Last verified: 2026-08-09 · đối chiếu tài liệu official/upstream

Mục tiêu

Dùng fd để tìm file nhanh nhưng hiểu ignore, hidden, symlink và khác biệt tên binary trên Debian/Ubuntu.

Yêu cầu tiên quyết

Có cây file lab; quyền cài package nếu fd/fdfind chưa có.

01 Bối cảnh thực tế

Khi tìm file cấu hình, log export hoặc source tree, find rất mạnh nhưng dài. fd tối ưu cho tương tác hằng ngày với syntax ngắn và filter rõ.

02 Kiến thức cốt lõi

  • Mặc định pattern là regex và chỉ match filename; -g dùng glob, -p match full path.
  • -t f giới hạn file, -e lọc extension, -H gồm hidden, -I bỏ ignore rules.
  • Ubuntu/Debian package fd-find dùng binary fdfind do xung đột tên; Fedora/FreeBSD dùng fd.

03 Các bước thực hiện

  1. Cài package và xác định binary thực tế fd hay fdfind.
  2. Tìm theo name/type trong path hẹp trước.
  3. So sánh mặc định với --hidden/--no-ignore khi cần.
  4. Dùng extension/type/exec có kiểm soát và xem danh sách trước khi hành động lên nhiều file.
Ubuntu / Xubuntu

Run as: user

sudo apt update && sudo apt install fd-find
fdfind --version
fdfind -t f -e conf . /etc
Debian

Run as: user

sudo apt update && sudo apt install fd-find
fdfind --version
fdfind -t f -e conf . /etc
Fedora

Run as: user

sudo dnf install fd-find
fd --version
fd -t f -e conf . /etc
FreeBSD — KHÁC Linux

Run as: root

sudo pkg install fd-find
fd --version
fd -t f -e conf . /etc

04 Kiểm chứng

Kết quả mong đợi

  • Tìm đúng file trong phạm vi đã chọn.
  • Giải thích được hidden/ignored file bị bỏ qua mặc định.
  • Ubuntu/Debian dùng đúng binary/package naming thay vì giả định giống Fedora/FreeBSD.

Tạo cây lab có file thường, hidden file và .gitignore để thấy khác biệt giữa default và unrestricted.

Ubuntu / Debian

Ubuntu / Debian

Run as: user

rm -rf /tmp/ld-fd && mkdir -p /tmp/ld-fd/cache
printf '*.tmp\n' > /tmp/ld-fd/.gitignore
touch /tmp/ld-fd/app.conf /tmp/ld-fd/cache/data.tmp /tmp/ld-fd/.secret.conf
fdfind -t f . /tmp/ld-fd
fdfind -HI -t f . /tmp/ld-fd

Fedora / FreeBSD

Fedora / FreeBSD

Run as: root

rm -rf /tmp/ld-fd && mkdir -p /tmp/ld-fd/cache
printf '*.tmp\n' > /tmp/ld-fd/.gitignore
touch /tmp/ld-fd/app.conf /tmp/ld-fd/cache/data.tmp /tmp/ld-fd/.secret.conf
fd -t f . /tmp/ld-fd
fd -HI -t f . /tmp/ld-fd

Expected Output

Lệnh mặc định bỏ hidden/ignored file; lệnh -HI hiển thị cả .secret.conf và data.tmp.

Cleanup / Revert

Cleanup

Run as: user

rm -rf /tmp/ld-fd

Gỡ / Hoàn tác

Hoàn tác thay đổi lab theo thứ tự ngược, khôi phục baseline đã ghi trước bài và kiểm chứng lại trước khi đóng phiên quản trị.

05 Lưu ý & Khắc phục lỗi

  • Dùng fd trên Ubuntu/Debian rồi gặp command khác hoặc command not found.
  • Quên hidden/ignore defaults và kết luận file không tồn tại.
  • Dùng -x/-X với lệnh xóa trước khi xem danh sách kết quả.

06 Lưu ý bảo mật

Khi tìm secret/config, giới hạn path và không paste kết quả nhạy cảm. Với exec mode, luôn chạy truy vấn read-only trước để kiểm tập kết quả.

07 Bài tập nhỏ để tự luyện

Tìm mọi file *.conf trong cây lab, kể cả hidden nhưng vẫn tôn trọng .gitignore; sau đó viết lệnh tương đương bằng find.
