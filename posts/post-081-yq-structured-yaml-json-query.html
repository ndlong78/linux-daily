yq: truy vấn YAML và JSON có cấu trúc mà không dùng regex

Đọc, lọc và chuyển đổi YAML/JSON theo cấu trúc thay vì grep/sed regex, đồng thời xác minh đúng implementation yq trước khi dùng.

TRỤC · CÔNG CỤ MỚIĐỘ KHÓ · CƠ BẢN~12 PHÚT
Runtime tested: —Documentation verified: Ubuntu/Xubuntu 26.04 LTS · Debian 13 stable · Fedora 44 · FreeBSD 15.1-RELEASELast verified: 2026-09-19

Mục tiêu

Dùng Mike Farah yq v4 để đọc field, lọc list và đổi định dạng YAML/JSON mà không parse cấu trúc bằng regex.

Yêu cầu tiên quyết

  • Có binary Mike Farah yq v4 trong PATH; bài này không cài package hoặc thay đổi cấu hình hệ thống.
  • Dùng user thường và file lab tạm, không thao tác trực tiếp trên config production.
  • Đặc biệt kiểm implementation: Debian 13 package yq mặc định là Python wrapper quanh jq, không phải Mike Farah yq v4; FreeBSD dùng package/port go-yq cho implementation Mike Farah.

01 Bối cảnh thực tế

Config YAML thường chứa object lồng nhau, list và boolean. Dùng grep/awk/sed có thể cho kết quả đúng với một file mẫu nhưng sai ngay khi indent, thứ tự key hoặc số phần tử thay đổi.

yq giải quyết bài toán ở tầng dữ liệu: truy cập key theo path, lọc phần tử theo điều kiện và xuất YAML/JSON có cấu trúc. Trước khi dùng, phải xác minh đúng implementation vì tên package yq không đồng nhất giữa distro.

02 Kiến thức cốt lõi

  • Path expression: .service.name đọc key theo cây dữ liệu, không phụ thuộc dòng nằm ở đâu.
  • Array iteration: .servers[] duyệt từng phần tử của list.
  • Filter: select(...) chọn object theo điều kiện thay vì lọc chuỗi output.
  • Output format: -o=json đổi representation mà không đổi ý nghĩa dữ liệu.
  • In-place edit: -i ghi trực tiếp file; với production phải backup/diff và review trước khi ghi.

03 Các bước thực hiện

  1. 1. Xác minh đúng implementation trước khi dùng

    Ubuntu/Xubuntu — kiểm binary và metadata package trước khi giả định

    Run as: user

    command -v yq
yq --version
apt-cache show yq 2>/dev/null | sed -n '1,12p'

    Debian 13 stable — KHÁC implementation mặc định

    Run as: user

    command -v yq
yq --version
apt-cache show yq 2>/dev/null | sed -n '1,12p'
apt-cache policy yq-go 2>/dev/null

    Debian stable mô tả package yq là YAML processor dùng jq ở phía sau. Không dùng cú pháp bài này cho binary đó nếu yq --version không phải Mike Farah v4.

    Fedora 44

    Run as: user

    command -v yq
yq --version
dnf info yq | sed -n '1,20p'

    FreeBSD — package Mike Farah là go-yq

    Run as: user

    command -v yq
yq --version
pkg info go-yq 2>/dev/null || pkg search -x 'go-yq'

  2. 2. Tạo file YAML lab

    Mọi hệ — cú pháp giống hệt nhau

    Run as: user

    workdir="$(mktemp -d)"
cat > "$workdir/app.yaml" <<'YAML'
service:
  name: api
  port: 8080
servers:
  - name: node-a
    enabled: true
  - name: node-b
    enabled: false
YAML
printf '%s\n' "$workdir/app.yaml"

  3. 3. Đọc scalar theo path

    Mọi hệ

    Run as: user

    yq '.service.name' "$workdir/app.yaml"
yq '.service.port' "$workdir/app.yaml"

    Kết quả phải là api và 8080; không cần biết chúng nằm ở dòng bao nhiêu.

  4. 4. Lọc phần tử trong array theo boolean

    Mọi hệ

    Run as: user

    yq '.servers[] | select(.enabled == true) | .name' "$workdir/app.yaml"

    Expression lọc theo kiểu boolean, không grep chuỗi enabled: true.

  5. 5. Chuyển subtree sang JSON để nối với tool khác

    Mọi hệ

    Run as: user

    yq -o=json '.servers' "$workdir/app.yaml"

    Dùng output JSON khi tool downstream cần format có cấu trúc thay vì parse text hiển thị.

  6. 6. Thử in-place edit trên bản copy lab

    Mọi hệ

    Run as: user

    cp "$workdir/app.yaml" "$workdir/app.edit.yaml"
yq -i '.service.port = 9090' "$workdir/app.edit.yaml"
diff -u "$workdir/app.yaml" "$workdir/app.edit.yaml" || true

    Chỉ dùng -i sau khi đã xác nhận target và có đường review/rollback phù hợp.

04 Kiểm chứng

Chạy lại ba truy vấn chính trên file lab và đối chiếu scalar, phần tử được lọc và port đã đổi trên bản copy.

Expected Output / Kết quả mong đợi

api
8080
node-a
9090

Thứ tự trên tương ứng với đọc name, đọc port gốc, lọc server enabled và đọc port của file đã chỉnh.

05 Lưu ý & Khắc phục lỗi

  • Cú pháp ví dụ không chạy: kiểm yq --version trước. Tên lệnh giống nhau không đảm bảo cùng implementation.
  • Debian 13: package yq trong stable là Python/jq wrapper; không coi nó là Mike Farah v4 chỉ vì binary cũng tên yq.
  • FreeBSD: implementation Mike Farah nằm ở port/package textproc/go-yq; port textproc/yq là implementation khác và xung đột tên binary.
  • Output có quote/format khác mong đợi: chọn output format rõ ràng và kiểm kiểu dữ liệu thay vì thêm regex hậu xử lý.

06 Bảo mật & vận hành

  • Không in toàn bộ file config có secret chỉ để lấy một field; truy vấn đúng path cần thiết.
  • Không đưa secret trực tiếp vào command line nếu shell history/process list có thể lộ giá trị.
  • Với production, ưu tiên đọc trước, tạo bản copy hoặc diff trước khi dùng -i.
  • Không dùng regex để “vá” YAML sau khi yq đã xuất dữ liệu có cấu trúc; giữ pipeline machine-readable càng lâu càng tốt.

07 Bài tập tự luyện

  1. Thêm node-c với enabled: true và viết expression trả về đúng hai node đang bật.
  2. Xuất riêng object service sang JSON rồi kiểm port bằng một JSON-aware tool.
  3. Ghi lại output yq --version trên một máy Debian/Fedora/FreeBSD và xác định implementation trước khi dùng cùng một expression.
