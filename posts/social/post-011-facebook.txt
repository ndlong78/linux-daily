🧩 SSH rớt giữa một tác vụ dài không phải lúc nào mọi process cũng chết theo cùng một cách — hành vi phụ thuộc shell, PTY và chương trình. Cách vận hành đáng tin hơn là tách terminal làm việc khỏi SSH client bằng tmux.

tmux chạy server trên máy chủ. Client có thể detach/disconnect rồi đăng nhập lại và attach vào session cũ. Workflow gọn nhất:
• tmux new -As work → attach nếu session đã có, tạo nếu chưa có
• Ctrl-b d → detach
• tmux ls → liệt kê session
• tmux attach -t work → quay lại

Cài đặt:
• Ubuntu/Xubuntu & Debian → apt install tmux
• Fedora → dnf install tmux
• FreeBSD → pkg install tmux (không nằm trong base)

Boundary quan trọng: tmux giúp sống qua SSH disconnect, KHÔNG tự sống qua reboot hoặc khi tmux server bị kill. Kiểm tmux -V trước khi copy option mới giữa các distro có package version khác nhau.
