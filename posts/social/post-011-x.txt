🧩 SSH rớt giữa job dài? Đừng giả định mọi process sẽ chết giống nhau. tmux tách terminal làm việc khỏi SSH client: session nằm trên máy chủ, client chỉ attach/detach. Thread 🧵

[Tweet 2]
Workflow gọn:
tmux new -As work   # attach nếu có, tạo nếu chưa có
Ctrl-b d            # detach
tmux ls
tmux attach -t work

[Tweet 3]
Cách dùng cốt lõi giống nhau trên 4 HĐH. Chỉ khác cài:
apt install tmux   # Ubuntu/Debian
dnf install tmux  # Fedora
pkg install tmux  # FreeBSD, không nằm trong base

[Tweet 4]
⚠️ Boundary: tmux giúp session sống qua SSH disconnect, nhưng KHÔNG tự sống qua reboot hoặc khi tmux server bị kill. Job cần tự khởi động sau reboot phải là systemd service/FreeBSD rc.d service.

[Tweet 5]
Package version có thể khác giữa distro. Trước khi copy option mới từ blog/docs, kiểm:
tmux -V
Core workflow rất ổn định; feature mới thì đừng đoán.

[Tweet 6]
Socket tmux mất chưa chắc session đã mất nếu server vẫn chạy. Upstream FAQ có cơ chế tạo lại socket bằng SIGUSR1. Đừng xóa/kill server chỉ vì không thấy socket path.
