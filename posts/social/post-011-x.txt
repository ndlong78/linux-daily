[Tweet 2]
tmux tách phiên làm việc khỏi kết nối SSH. Mọi thứ chạy trong tmux server TRÊN MÁY CHỦ — client rớt chỉ "detach", việc vẫn chạy tiếp. Đăng nhập lại → attach → về đúng chỗ.

[Tweet 3]
Cốt lõi, phím prefix là Ctrl-b (C-b):
tmux new -s work    # tạo phiên
C-b d               # detach
tmux ls             # liệt kê phiên
tmux attach -t work # quay lại

[Tweet 4]
Chia màn hình để vừa chạy vừa theo dõi:
C-b %   chia dọc (trái | phải)
C-b "   chia ngang (trên / dưới)
C-b c   cửa sổ mới (như tab)
