[Tweet 2]
Nếu script cần Bash, #!/usr/bin/env bash hữu ích vì env tìm bash qua PATH. Nhưng đó cũng là điều kiện: cron, sudo hay service có thể dùng PATH khác shell tương tác.

[Tweet 3]
set -euo pipefail là guardrail, không phải “mọi lỗi đều dừng”. -e có ngoại lệ trong if, while/until, &&/|| và nhiều ngữ cảnh pipeline. Bước quan trọng nên kiểm trạng thái rõ ràng.

[Tweet 4]
Không cần đặt global IFS=$'\n\t' như công thức mặc định. Ưu tiên quote biến; khi cần đọc theo delimiter, đặt IFS cục bộ, ví dụ: while IFS= read -r line.

[Tweet 5]
Trong script, dùng command -v bash thay cho which. Với lệnh destructive, validate biến trước; đừng dựa vào guardrail như GNU rm --preserve-root để cứu một path rỗng.

[Tweet 6] — FreeBSD
Bash không nằm trong FreeBSD base. Cài package bash, rồi kiểm command -v bash. Nếu dùng env bash, nhớ rằng interpreter vẫn được tìm qua PATH của môi trường chạy.
