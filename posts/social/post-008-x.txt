Linux (Ubuntu/Debian/Fedora) — iproute2:
ip link / ip addr
ip route
ss -tlnp
Bộ ifconfig/netstat cũ đã lỗi thời, Fedora còn không cài sẵn.

[Tweet 4] — FreeBSD
FreeBSD giữ bộ BSD gốc, KHÔNG có ip/ss:
ifconfig            # interface + IP
netstat -rn         # route
sockstat -4 -l      # cổng nghe
arp -a              # bảng ARP

[Tweet 5]
Ánh xạ nhanh khi đổi ngữ cảnh:
ip addr → ifconfig
ip route → netstat -rn
ss -tlnp → sockstat -4 -l
ip neigh → arp -a
Riêng ping/traceroute/tcpdump: hai bên y hệt.
