[Tweet 2]
Hầu hết module POSIX cần Python trên managed node. Nếu host tối thiểu chưa có Python:
ansible bsd1 -m ansible.builtin.raw -a 'pkg install -y python3'
raw không cần Python.

[Tweet 3]
Phần giao nhau đa HĐH nên bắt đầu bằng:
ansible.builtin.package
ansible.builtin.service
Chúng proxy sang package/service manager thực tế. Tên gói vẫn có thể khác giữa distro.

[Tweet 4]
FreeBSD nuance:
community.general.pkgng không thuộc ansible-core.
Nếu dùng:
ansible-galaxy collection install community.general
và nên pin collection trong requirements.yml.

[Tweet 5]
doas become cũng thuộc community.general, không phải builtin của ansible-core. Kiểm collection trước khi kỳ vọng ansible_become_method hoạt động.
