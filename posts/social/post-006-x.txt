[Tweet 2]
Ansible chạy từ 1 control node, đẩy lệnh qua SSH — KHÔNG agent thường trực. Đổi lại: máy đích phải có sẵn Python. Khi kết nối, nó thu "facts", trong đó ansible_os_family để bạn rẽ nhánh.

[Tweet 3]
Rẽ nhánh module theo họ:
apt  → os_family "Debian" (Ubuntu + Debian)
dnf  → "RedHat" (Fedora)
pkgng → "FreeBSD"
Bật dịch vụ dùng chung module service, state: started + enabled: true.

[Tweet 4] — FreeBSD
⚠️ FreeBSD: bản tối thiểu KHÔNG có Python → ping/facts lỗi. Bootstrap trước:
ansible bsd1 -m raw -a "pkg install -y python3"
rồi đặt ansible_python_interpreter=/usr/local/bin/python3

[Tweet 5] — FreeBSD
⚠️ FreeBSD không có sudo mặc định → become bằng doas (ansible_become_method: doas) hoặc cài sudo. enabled: true ghi vào /etc/rc.conf, không tạo systemd unit.

[Tweet 6]
Luôn xem trước rồi mới áp:
ansible-playbook ... --check --diff
Playbook idempotent chạy lần hai phải báo changed=0. Còn changed = task chưa thật sự khai báo trạng thái.
