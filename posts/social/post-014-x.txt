Hệ backup đáng tin = 5 mắt xích, ghép cả chu kỳ:
1 đĩa đích riêng (#010)
2 script vững restic (#013+#004)
3 user tối thiểu quyền (#009)
4 lập lịch (#012)
5 diễn tập khôi phục ← quyết định

[Tweet 3]
Script vững (giống nhau mọi HĐH):
#!/usr/bin/env bash
set -euo pipefail
trap 'logger -t backup "FAIL dòng $LINENO"' ERR
restic backup /etc /var/www
restic forget --keep-daily 7 --prune

[Tweet 4]
Lập lịch — Ubuntu/Debian/Fedora dùng systemd timer:
[Timer] OnCalendar=*-*-* 02:00:00 / Persistent=true
[Service] User=backup
systemctl enable --now backup.timer

[Tweet 5] — FreeBSD
FreeBSD KHÔNG có systemd timer → dùng cron:
crontab -u backup -e
0 2 * * *  /usr/local/bin/backup.sh
Log ở /var/log (không phải journalctl). restic cài từ pkg.
