[Tweet 3]
Mở đúng 22/80/443, chặn còn lại:
Ubuntu/Debian — ufw:
ufw allow OpenSSH
ufw allow 80/tcp && ufw allow 443/tcp
ufw enable
(Debian tối giản: apt install ufw trước)

[Tweet 4]
Fedora — firewalld:
firewall-cmd --permanent --add-service={ssh,http,https}
firewall-cmd --reload
⚠️ Quên --permanent là luật bay sau reboot.

[Tweet 5] — FreeBSD
FreeBSD dùng pf, KHÔNG có ufw/firewalld. /etc/pf.conf:
pass in on em0 proto tcp to port { 22 80 443 } keep state
Bật: sysrc pf_enable=YES && service pf start
