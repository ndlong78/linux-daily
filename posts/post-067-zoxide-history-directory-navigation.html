Công cụ mới · zoxide

zoxide: điều hướng thư mục theo lịch sử mà không thay thế cd trong script

Dùng zoxide cho shell tương tác; trong script vẫn giữ cd và path tường minh để hành vi có thể dự đoán.

TRỤC · CÔNG CỤ MỚIĐỘ KHÓ · CƠ BẢN~10 PHÚT
Tested on: Ubuntu/Xubuntu 24.04 LTS · Debian 13 stable · Fedora 42 · FreeBSD 14.4-RELEASELast verified: 2026-09-05

Mục tiêu

Cài và khởi tạo zoxide cho shell tương tác, đọc database xếp hạng, dùng z/zi đúng ngữ cảnh và giữ automation độc lập với lịch sử cá nhân.

Yêu cầu tiên quyết

  • Shell tương tác Bash hoặc shell tương thích với hướng dẫn init của zoxide.
  • Ubuntu và Xubuntu dùng cùng nhánh hướng dẫn; Debian dùng cùng quy trình tải installer khi package distro không được upstream khuyến nghị. Fedora và FreeBSD dùng package manager riêng.
  • Cần Internet để cài lần đầu. Các thao tác lab chạy bằng user thường, trừ bước cài package Fedora/FreeBSD.

01 Bối cảnh thực tế

Khi làm việc với nhiều repository, gõ lại các đường dẫn dài làm chậm thao tác. zoxide ghi nhận các thư mục đã dùng và cho phép nhảy tới kết quả có thứ hạng phù hợp bằng vài từ khóa.

Điểm quan trọng là database này mang tính cá nhân và thay đổi theo lịch sử. Vì vậy zoxide phù hợp cho terminal tương tác, còn script production nên dùng cd và path đã biết thay vì phụ thuộc vào rank của một user.

02 Kiến thức cốt lõi

  • zoxide init sinh shell integration; lệnh z và zi chỉ xuất hiện sau khi shell nạp phần init đó.
  • Database có rank. zoxide theo dõi các thư mục thường dùng và tìm kết quả phù hợp thay vì coi từ khóa là path tuyệt đối.
  • zoxide query cho phép xem kết quả mà không đổi thư mục, hữu ích khi cần kiểm chứng trước khi nhảy.
  • Không thay cd trong script. Script cần hành vi deterministic, không phụ thuộc lịch sử tương tác của người chạy.

03 Các bước thực hiện

  1. 1. Cài zoxide trên Ubuntu/Xubuntu và Debian theo installer upstream có kiểm tra

    Ubuntu/Xubuntu

    Run as: user

    curl -fsSLo /tmp/zoxide-install.sh https://raw.githubusercontent.com/ajeetdsouza/zoxide/main/install.sh
less /tmp/zoxide-install.sh
sh /tmp/zoxide-install.sh

    Debian

    Run as: user

    curl -fsSLo /tmp/zoxide-install.sh https://raw.githubusercontent.com/ajeetdsouza/zoxide/main/install.sh
less /tmp/zoxide-install.sh
sh /tmp/zoxide-install.sh

    Không nối trực tiếp curl vào shell. Đọc file installer trước khi chạy. Nếu installer thêm ~/.local/bin, mở shell mới hoặc cập nhật PATH theo thông báo của installer.

  2. 2. Cài bằng package manager trên Fedora

    Fedora

    Run as: sudo

    sudo dnf install zoxide

  3. 3. Cài bằng pkg trên FreeBSD

    FreeBSD — KHÁC Linux

    Run as: root

    pkg install zoxide

    FreeBSD không dùng apt, dnf hay systemd cho bước này.

  4. 4. Kiểm binary trước khi sửa cấu hình shell

    Mọi hệ

    Run as: user

    command -v zoxide
zoxide --version

    Expected Output: dòng đầu là đường dẫn tới binary zoxide; dòng sau in phiên bản đã cài.

  5. 5. Khởi tạo zoxide cho Bash

    Ubuntu/Xubuntu · Debian · Fedora · FreeBSD dùng Bash

    Run as: user

    printf '\neval "$(zoxide init bash)"\n' >> "$HOME/.bashrc"
. "$HOME/.bashrc"
type z

    Expected Output: type z cho biết z là function do zoxide tạo. Nếu dùng shell khác, dùng cú pháp init tương ứng trong tài liệu upstream thay vì chép Bash config.

  6. 6. Tạo lab và để zoxide ghi nhận lịch sử

    Mọi hệ

    Run as: user

    mkdir -p "$HOME/zoxide-lab/alpha" "$HOME/zoxide-lab/beta-project"
cd "$HOME/zoxide-lab/alpha"
cd "$HOME/zoxide-lab/beta-project"
cd "$HOME"

    Các lần đổi thư mục sau khi init giúp database tích lũy history cho user hiện tại.

  7. 7. Query trước, rồi nhảy bằng từ khóa

    Mọi hệ

    Run as: user

    zoxide query beta-project
z beta-project
pwd

    Expected Output: query trả về đường dẫn kết thúc bằng /zoxide-lab/beta-project; sau z beta-project, pwd trỏ tới cùng thư mục.

04 Kiểm chứng

Mọi hệ

Run as: user

zoxide query --list | grep 'zoxide-lab'
zoxide query alpha
zoxide query beta-project

Kết quả mong đợi: database chứa các thư mục lab và từng query trả về path phù hợp. Nếu không có kết quả, xác nhận shell đã nạp zoxide init trước khi truy cập các thư mục.

Gỡ / Hoàn tác

Xóa dòng eval "$(zoxide init bash)" khỏi ~/.bashrc, rồi mở shell mới.

Fedora

Run as: sudo

sudo dnf remove zoxide

FreeBSD

Run as: root

pkg delete zoxide

Với Ubuntu/Xubuntu hoặc Debian cài bằng installer upstream, chạy command -v zoxide để xác nhận vị trí binary trước khi xóa file do installer tạo. Không dùng rm -rf theo đường dẫn đoán.

05 Lưu ý & Khắc phục lỗi

  • z: command not found: shell chưa nạp output của zoxide init; kiểm ~/.bashrc và mở shell mới.
  • Query không thấy thư mục: truy cập thư mục sau khi init hoặc dùng zoxide add <directory> để thêm tường minh.
  • Nhiều kết quả gần giống: thêm từ khóa để thu hẹp; dùng zi khi đã cài fzf phù hợp.
  • Script chạy khác giữa máy: loại z khỏi script và quay về cd <known-path>.

06 Bảo mật & vận hành

  • Database zoxide phản ánh tên/path thư mục từng dùng; không đưa file database cá nhân vào repository hay log công khai.
  • Đặt biến môi trường cấu hình trước zoxide init nếu cần thay data directory hoặc exclude path.
  • Không dùng lịch sử/rank của zoxide làm input cho job tự động, cron, systemd timer hoặc FreeBSD periodic.

07 Bài tập tự luyện

  1. Tạo ba thư mục có tên gần giống, truy cập với tần suất khác nhau rồi so kết quả zoxide query.
  2. Dùng zoxide query --list để xác nhận database thay đổi sau khi truy cập thêm một thư mục.
  3. Viết một shell script nhỏ dùng cd <known-path> và giải thích vì sao không thay bằng z <keyword>.
