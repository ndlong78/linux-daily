Công cụ mới · jq

jq: biến JSON thành dữ liệu vận hành dùng được

API và CLI hiện đại trả JSON ngày càng nhiều. jq giúp lọc field, map array và tạo output ổn định mà không grep JSON như text thường.

TRỤC · CÔNG CỤ MỚIĐỘ KHÓ · CƠ BẢN

01 Bối cảnh thực tế

API, cloud CLI và inventory tools thường trả JSON. Một pipeline grep/cut dễ vỡ khi key đổi thứ tự hoặc khoảng trắng thay đổi.

02 Kiến thức cốt lõi

  • ., .field, .[], select(...) và pipe | là các khối cơ bản.
  • Dùng -r khi shell cần raw string; mặc định jq xuất JSON quoted.
  • Kiểm type/key trước khi đưa output API vào automation.

04 Ví dụ thực hành từng bước

Tạo dữ liệu lab ba service và lấy tên service đang down.

Linux

Linux
cat > /tmp/ld-services.json <<'JSON'
{"services":[{"name":"api","state":"up"},{"name":"db","state":"down"},{"name":"web","state":"up"}]}
JSON
jq -r '.services[] | select(.state == "down") | .name' /tmp/ld-services.json

FreeBSD

FreeBSD
cat > /tmp/ld-services.json <<'JSON'
{"services":[{"name":"api","state":"up"},{"name":"db","state":"down"},{"name":"web","state":"up"}]}
JSON
jq -r '.services[] | select(.state == "down") | .name' /tmp/ld-services.json

Expected Output

Một dòng duy nhất: db.

Cleanup / Revert

Linux / FreeBSD
rm -f /tmp/ld-services.json

05 Cạm bẫy / lỗi thường gặp và cách xử lý

  • Quên -r rồi truyền chuỗi có dấu quote sang lệnh khác.
  • Giả định key luôn tồn tại mà không xử lý dữ liệu thiếu.
  • Parse JSON bằng grep/cut và phụ thuộc format text.

06 Lưu ý bảo mật

JSON từ API có thể chứa token/PII. Chỉ log field cần thiết và bảo vệ file tạm chứa dữ liệu nhạy cảm.

07 Bài tập nhỏ để tự luyện

Thêm latency_ms và dùng jq in service có state == "up" nhưng latency lớn hơn 100 ms.
