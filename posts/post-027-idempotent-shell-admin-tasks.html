Automation · Idempotency

Shell idempotent: chạy lại không phá trạng thái

Automation vận hành phải chịu được việc chạy lại sau timeout, retry hoặc nửa chừng. Mục tiêu là cùng input tạo cùng trạng thái cuối, không nhân bản dòng cấu hình hay restart vô hạn.

TRỤC · AUTOMATIONĐỘ KHÓ · TRUNG CẤP

Tested on: Ubuntu/Xubuntu 24.04 LTS · Debian 13 stable · Fedora 42 · FreeBSD 14.3-RELEASE

Last verified: 2026-08-09 · đối chiếu tài liệu official/upstream

Mục tiêu

Viết shell automation idempotent: chạy lại cùng input không nhân bản cấu hình hay tạo thay đổi vô nghĩa.

Yêu cầu tiên quyết

Dùng resource lab; chọn POSIX sh hoặc Bash rõ ràng theo tính năng dùng.

01 Bối cảnh thực tế

Khi job bị retry hoặc chạy lại sau timeout, script không được nhân bản cấu hình hay restart service vô hạn. Idempotency biến “chạy lại” thành thao tác an toàn thay vì một rủi ro mới.

02 Kiến thức cốt lõi

  • Kiểm trạng thái trước khi sửa: file có tồn tại, nội dung có khác, mode có đúng.
  • Tách check → change → verify; chỉ reload/restart khi thay đổi thật.
  • Dùng cú pháp POSIX /bin/sh nếu muốn cùng script chạy trên Linux và FreeBSD; tránh Bash-only như array hoặc [[ ... ]].

03 Các bước thực hiện

  1. Mô tả desired state trước khi mutate.
  2. Thêm guard để chỉ đổi khi current state khác desired state.
  3. Chạy lần một và ghi nhận thay đổi.
  4. Chạy lần hai; state/diff phải không đổi.

04 Kiểm chứng

Kết quả mong đợi

  • Lần đầu đưa lab về desired state.
  • Lần hai không tạo duplicate hay diff mới.
  • Verification độc lập xác nhận trạng thái cuối.

Lab tạo một file cấu hình trong /tmp; lần đầu phải thay đổi, lần hai phải giữ nguyên.

Linux

Linux

Run as: user

cat > /tmp/ld-idempotent.sh <<'SH'
#!/bin/sh
set -eu
target=/tmp/ld-managed.conf
tmp=$(mktemp)
trap 'rm -f "$tmp"' 0 HUP INT TERM
printf '%s\n' 'mode=managed' > "$tmp"
if [ ! -f "$target" ] || ! cmp -s "$tmp" "$target"; then
  install -m 0644 "$tmp" "$target"
  echo CHANGED
else
  echo UNCHANGED
fi
cmp -s "$tmp" "$target"
SH
chmod +x /tmp/ld-idempotent.sh
/bin/sh /tmp/ld-idempotent.sh
/bin/sh /tmp/ld-idempotent.sh

FreeBSD

FreeBSD

Run as: root

/bin/sh /tmp/ld-idempotent.sh
/bin/sh /tmp/ld-idempotent.sh
cat /tmp/ld-managed.conf

Expected Output

Lần đầu in CHANGED; lần thứ hai in UNCHANGED; file chỉ có một dòng mode=managed.

Cleanup / Revert

Linux / FreeBSD

Run as: user

rm -f /tmp/ld-idempotent.sh /tmp/ld-managed.conf

Gỡ / Hoàn tác

Hoàn tác thay đổi lab theo thứ tự ngược, khôi phục baseline đã ghi trước bài và kiểm chứng lại trước khi đóng phiên quản trị.

05 Lưu ý & Khắc phục lỗi

  • Dùng >> mỗi lần chạy và tạo dòng trùng.
  • Restart service dù config không đổi.
  • Gắn shebang /bin/sh nhưng dùng cú pháp chỉ Bash hiểu.

06 Lưu ý bảo mật

Dùng mode/umask rõ ràng, file tạm khó đoán và không ghi secret vào stdout. Với file hệ thống, backup và verify trước khi replace.

07 Bài tập nhỏ để tự luyện

Mở rộng script để quản lý thêm key owner; chứng minh lần chạy thứ hai không đổi checksum của file.
